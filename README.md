# ☕ Core Java Workshop

This repository contains all the programs, assignments, and practice exercises that I completed during my **Core Java Workshop**. It covers the fundamental concepts of Java programming with practical examples.

## 📚 Workshop Overview

The Core Java Workshop focused on building a strong foundation in Java programming, including object-oriented programming concepts and hands-on coding practice.

## 🚀 Topics Covered

- Introduction to Java
- Java Installation & IDE Setup
- Variables and Data Types
- Operators
- Input & Output
- Conditional Statements
- Loops
- Arrays
- Strings
- Methods
- Constructors
- Object-Oriented Programming (OOP)
  - Classes & Objects
  - Encapsulation
  - Inheritance
  - Polymorphism
  - Abstraction
- Exception Handling
- Packages
- Collections Framework
- File Handling
- Multithreading (Basics)
- JDBC (Basics)
